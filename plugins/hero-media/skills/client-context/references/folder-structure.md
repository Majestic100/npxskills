# Client folder structure

Every client gets the same folders, copied from `TEMPLATES/[TEMPLATE] Client Folder`.

```
[ACTIVE] Clients/
  <Client name>/
    Context/        Client Context I <Client> (doc), Learning Log I <Client> (sheet),
                    logo, fonts, brand guide, strategy and research. Internal only.
    Content/
      Scripts/      Video and social scripts (docs)
      Planning/     Content plans (docs and sheets)
    Reporting/      Reports to the client
    Agreements/     Contracts, quotes, agreements
```

## Rules

- **Folder names are in English**, exactly as above.
- **Video and images live in Frame.io**, not in Drive: raw footage, edits, versions and client feedback. `Content` in Drive holds documents only.
- **Sharing:** share `Content`, `Reporting` and `Agreements` with the client one by one. Never share the client folder itself, because that would expose `Context`.
- **One client per folder.** A sub-brand or another client never sits inside a client's folder.
- **Subfolders only when needed**, for example a market folder (DK, SE, NL) for a multi-market client.
- **Inactive clients** move to `[ARKIV] Clients` with their whole folder.
